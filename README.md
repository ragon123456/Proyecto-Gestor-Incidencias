---

## Descripción del Proyecto

Aplicación web centralizada diseñada para registrar y resolver incidencias informáticas. Permite a los usuarios abrir tickets detallando la avería (Hardware, Software o Redes) y facilita al personal técnico su asignación, seguimiento, respuesta y actualización de estado en tiempo real.

---

## Funcionalidades Principales

* **Gestión de Usuarios:** Registro e inicio de sesión con roles diferenciados (*Usuario*, *Técnico*, *Administrador*).
* **Creación de Tickets:** Formulario para reportar averías con título, descripción, categoría y prioridad.
* **Panel Técnico:** Asignación y autoasignación de incidencias, sistema de comentarios y cambio de estado (*Abierto*, *En Proceso*, *Pendiente*, *Resuelto*, *Cerrado*).
* **Registro de Solución:** Documentación de la resolución técnica al cerrar el ticket para mantener un historial de soluciones.

---

## Tecnologías y Herramientas

* **Frontend:** HTML5 y CSS3 (prototipado previo en Figma).
* **Backend:** PHP.
* **Base de Datos:** MySQL (gestionada con HeidiSQL / phpMyAdmin).
* **Entorno Local y Control de Versiones:** Laragon, Visual Studio Code y GitHub.
