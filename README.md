# TicketDesk - Sistema Web de Gestión de Incidencias Informáticas

Proyecto Intermodular del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) - Modalidad Virtual (FPEuroformac).

Autor: Rafael José González Sánchez
Tutora: Simona
Curso: 2026-2027

## Descripción del Proyecto

Aplicación web centralizada diseñada para agilizar el soporte técnico interno. 
Permite a los usuarios reportar incidencias informáticas mediante tickets y facilita al personal técnico su asignación, seguimiento, respuesta y cambio de estado en tiempo real.

## Funcionalidades Principales Gestión de Usuarios: Inicio de sesión diferenciado para Usuarios y Técnicos.

Creación de Tickets: Formulario para reportar averías con título, descripción y prioridad.
Panel Técnico: Listado de incidencias donde el técnico puede asignarse un ticket, escribir respuestas y cambiar su estado (Abierto, En Proceso, Resuelto).

## Tecnologías Previstas

Diseño Web (Frontend): HTML5 y CSS3.
Programación (Backend): PHP (con servidor local XAMPP).
Base de Datos: MySQL (gestionada con phpMyAdmin).
Control de Versiones: GitHub.
